# 基线校准器使用说明

## 这是什么

一个网页工具，**不用装 PS**，靠拖滑块把「你的复刻」调到和「原牢图」一样。

调完点保存，得到一份配方 JSON。那就是基线。

---

## 怎么打开

**双击项目根目录的 `启动校准器.bat`**

会弹出命令行窗口并自动打开浏览器。关掉命令行窗口即停止。

如果浏览器没自动打开，手动访问：`http://127.0.0.1:8848`

---

## 界面长什么样

```
┌────────────────────────────────────────────────┬──────────────┐
│  牢图棒 · 基线校准器        [参考=当前基底][重置][保存为基线] │
├────────────────────────┬───────────────────────┼──────────────┤
│                        │                       │ 基底│操作│JSON│说明 │
│   参考（原牢图）        │   你的复刻            │              │
│                        │   ↑ 可拖动元素        │  <op 卡片>   │
│                        │                       │              │
├────────────────────────┴───────────────────────┤              │
│ 渲染 214ms │ 尺寸 900×805 │ 配方 合法 │ 素材 4 │              │
└────────────────────────────────────────────────┴──────────────┘
```

左边两栏固定：**左=原牢图，右=你的复刻**。目标就是把右边调到看起来像左边。

## 完整操作流程

### 第 1 步：选基底和参考

在「基底」标签页：

| 控件 | 选什么 |
|---|---|
| 基底图 | 要被改的那张图（比如 `image copy.png` 砂金） |
| 参考图 | 原牢图（就是同一张，方便左右对比） |

> 校准阶段基底和参考通常**选同一张**——因为你是在「复现这张图的做法」。

### 第 2 步：选子类型

| 类型 | 特征 | 调参重点 |
|---|---|---|
| **A 精贴** | 写实脸塞进二次元头，看不出来 | `edge` 设 none，靠前景掩码挡 |
| **B 畸变** | 五官被拉扯变形 | `stretch_x` 拉歪 + `degrade` 调糊 |
| **C 堆叠** | 一堆无关物件乱摆 | 位置、大小、层序 |
| **D 换装** | 真实纹理穿上二维角色 | `texture_wrap` 四个角点 |

### 第 3 步：加操作（「操作」标签页）

1. 下拉框选一个 op
2. 点「+ 添加」
3. 卡片展开，开始拖滑块

**常用组合**：

```
B 畸变： feature_warp ×2（眼、嘴） → degrade → label
C 堆叠： sticker ×N                → degrade
D 换装： face_fit → texture_wrap → sticker → label
A 精贴： face_fit（edge=none）      →（无 degrade）
```

### 第 4 步：调参

每个 op 展开后有滑块 + 数字框，两边同步。

**可以做的事**：
- 拖滑块，右边 180ms 后自动刷新
- **在右边图上直接拖**，移动当前选中元素的位置
- 数字框里输入精确值

**调参顺序建议**（很重要）：

1. **先定位置**（center / target_box），位置对了再调别的
2. **再调大小**（scale / stretch）
3. **再调形变**（stretch_x / skew_deg / keep_skin_rim）
4. **最后调降质**（degrade）—— 因为降质会掩盖其他问题，太早调容易误判

### 第 5 步：保存

点右上角「保存为基线」，或底部输入文件名后点「保存」。

会同时写两份：

```
docs/baselines/baseline_B.json   ← 基线存档
recipes/baseline_B.json           ← M1 直接复用
```

## 参数速查

### feature_warp（五官形变，B 类核心）

| 参数 | 作用 | 调到什么程度 |
|---|---|---|
| `stretch_x` | 横向拉伸 | **1.8~2.5** 才有「明显歪」 |
| `stretch_y` | 纵向拉伸 | 0.9~1.9，嘴通常要放大 |
| `skew_deg` | 斜挑 | **10~15** 出斜挑眼 |
| `keep_skin_rim` | 带一圈皮肤 | **0.2~0.25** 才有色块边界 |
| `target_box` | 塞进哪个孔位 | 按角色五官位置量 |

### degrade（降质，B 类必开）

| 参数 | 作用 | 参考值 |
|---|---|---|
| `downscale` | 降分辨率 | **0.6~0.7** |
| `jpeg_quality` | 压缩块 | **35~45** |
| `noise` | 噪点 | 0.01~0.03 |
| `oversharpen` | 边缘白边 | weak / medium |

### sticker（物件放置，C 类核心）

| 参数 | 作用 |
|---|---|
| `center` | 位置（0~1 归一化，图上可拖） |
| `scale` | 相对基底长边的大小 |
| `z` | 层序，大者在上 |

### texture_wrap（纹理透视，D 类核心）

`quad` 是四个角点，顺序：**左上 → 右上 → 右下 → 左下**。

对准角色身体的轮廓四个角。这是 D 类成败的关键。

## 常见问题

**Q：拖动滑块后右边没反应？**
A：等 200ms 左右。如果一直不动，看状态栏是否卡在「渲染中…」，或按 F12 看报错。

**Q：配方显示「有问题」？**
A：看红色提示。最常见是 `degrade` 没启用（B 类要求必开）。

**Q：素材列表是空的？**
A：需要先把图放进素材库：
```
.venv\Scripts\python.exe tools\add_asset.py 你的图.png --name 素材名
```

**Q：能撤销吗？**
A：单个参数可以用 Ctrl+Z（浏览器的输入撤销）。整体重来点「重置」。

**Q：保存了但找不到文件？**
A：在 `docs/baselines/` 和 `recipes/` 两个目录下。
