## 一、C 类 · 堆叠（REF-C）

**复刻目标**：科比姿势图 + 一串呜喵王 + 搪瓷盆放在屁股位置。

### 结构拆解

| 元素 | 角色 | 大约位置（归一化） | 观察 |
|---|---|---|---|
| 主体人物 | 基底 | 占画面左下 2/3 | 趴姿 |
| 搪瓷盆 | 关键物件 | 中心约 (0.47, 0.58) | 贴在臀部，**无透视、无投影** |
| 呜喵王一串 | 重复物件 | 从盆向下垂到 (0.42, 0.85) | 大小递减 |
| 呜喵王另一串 | 重复物件 | 左侧人物手上，约 (0.22, 0.52) | 当钥匙扣 |
| 青花碗 | 次要件 | 盆的上方 | 与盆叠放 |
| 背景 | 纯蓝幕 | 全画布 | 棚拍背景 |

### 参数表

| 参数 | 复刻值 | 备注 |
|---|---|---|
| `base_transform.flip_x` | `[~]` | 待确认是否翻转 |
| `sticker[盆].center` | `[~] 0.47, 0.58` | 目测 |
| `sticker[盆].scale` | `[~] 0.22` | 相对基底长边 |
| `sticker[盆].rotation_deg` | `[~] 0` | 正放 |
| `sticker[盆].z` | `[~] 3` | 压在人物上 |
| `sticker[呜喵王].center` | `[~] 0.42, 0.62 → 0.42, 0.85` | 串联，逐个递减 |
| `sticker[呜喵王].scale` | `[~] 0.12 → 0.06` | 递减 |
| `sticker[呜喵王].z` | `[~] 2` | 在盆下 |
| `degrade.enabled` | `[~] true` | 有压缩痕迹 |
| `degrade.downscale` | `[~] 0.85` | 略降 |
| `degrade.jpeg_quality` | `[~] 60` | 中等 |
| `degrade.noise` | `[~] 0.01` | 轻微 |
| `degrade.oversharpen` | `[~] off` | 无明显白边 |

### 关键观察（写进实现要求）

1. **完全不考虑透视**：盆贴上去没有任何形变，就是平贴。
2. **完全没有投影**：盆和呜喵王都不在地上留影子。
3. **物件边缘是硬边**：没有羽化，抠图留了白边/杂边也没修。
4. **违反物理**：盆浮在臀部，没有支撑物。这是笑点来源（违和轴 ⑤）。

### 验收判据

> 复刻出来以后，和 REF-C 并排看，**「盆在哪、串怎么排、有没有影子」这三件事对得上**即算达标。像素级接近不是目标。

## 二、D 类 · 换装（REF-D）

**复刻目标**：Q 版角色 + 科比脸 + 湖人球衣 + 冰红茶。

### 结构拆解

| 元素 | 角色 | 观察 |
|---|---|---|
| Q 版角色 | 基底 | 棕色兽耳、白底 |
| 科比脸 | 贴在头部 | **横向拉伸**，笑容被拉宽 |
| 湖人球衣 | 纹理裹到身体 | 真实照片纹理，**有透视贴合** |
| 冰红茶 | 物件 | 在角色手上，**贴上去的** |
| 背景 | 纯白 | 抠图底 |

### 参数表

| 参数 | 复刻值 | 备注 |
|---|---|---|
| `face_fit.center` | `[~] 0.5, 0.32` | 头部位置 |
| `face_fit.scale` | `[~] 1.15` | 略放大 |
| `face_fit.edge` | `[~]hard` | 硬边 |
| `face_fit.color_transfer` | `[~] 0` | 完全不做 |
| `face_fit.flip_x` | `[~]` | 待确认 |
| `texture_wrap.quad` | `[~] [[0.32,0.44],[0.68,0.44],[0.70,0.78],[0.30,0.78]]` | 身体轮廓四角 |
| `texture_wrap.blend` | `[~] normal` | 直接盖 |
| `sticker[冰红茶].center` | `[~] 0.74, 0.66` | 手上 |
| `sticker[冰红茶].scale` | `[~] 0.14` | |
| `sticker[冰红茶].z` | `[~] 5` | 最上 |
| `degrade.enabled` | `[~] false` | **纯白底，高频能量最低（0.0070）** |

### 关键观察

1. **球衣是真透视贴**：不是简单覆盖，是四角对齐后 warp 的。这是 D 类唯一有技术含量的地方。
2. **脸被拉伸过**：科比脸比原比例宽，说明用了 `stretch_x` 而非纯缩放——**这个子类型和 B 类有交叉**。
3. **纯白背景不降质**：实测高频能量 0.0070 是四张最低，但那是因为大面积纯白，不是降质造成的。

### 验收判据

> 球衣能贴着身体曲面走、脸明显被拉宽、冰红茶在手上——三点对得上即达标。

## 三、B 类 · 畸变（REF-B）

**复刻目标**：砂金的脸保留，只把牙膏 logo 的眼睛和嘴移植进去并暴力拉伸。

### 结构拆解

| 元素 | 角色 | 观察 |
|---|---|---|
| 砂金头部 | 基底，**完整保留** | 白灰头饰有明确开口 |
| 移植眼 | 单块五官 | **横向拉伸 + 斜挑**，撑满孔位 |
| 移植嘴 | 单块五官 | **纵向放大到占半张脸** |
| 深棕色皮肤边 | 色块边界 | 眼/嘴带了一圈周围皮肤 |

### 参数表

| 参数 | 复刻值 | 备注 |
|---|---|---|
| `feature_warp[眼].target_box` | `[~] [0.34, 0.30, 0.32, 0.10]` | 按孔位 |
| `feature_warp[眼].stretch_x` | `[~] 1.9` | **明显拉宽** |
| `feature_warp[眼].stretch_y` | `[~] 0.9` | 略压 |
| `feature_warp[眼].skew_deg` | `[~] 14` | **斜挑** |
| `feature_warp[眼].keep_skin_rim` | `[~] 0.25` | 带皮边 |
| `feature_warp[嘴].target_box` | `[~] [0.35, 0.50, 0.30, 0.22]` | |
| `feature_warp[嘴].stretch_x` | `[~] 2.5` | **最夸张的一项** |
| `feature_warp[嘴].stretch_y` | `[~] 1.8` | **纵向也放大** |
| `feature_warp[嘴].keep_skin_rim` | `[~] 0.2` | |
| `label.text` | `牢肘子` | 小字 |
| `label.anchor` | `[~] bottom_right` | |
| `label.size_ratio` | `[~] 0.028` | **小，像水印** |
| `degrade.enabled` | `true` | **必开** |
| `degrade.downscale` | `[~] 0.60` | **四张里最低** |
| `degrade.jpeg_quality` | `[~] 35` | **明显块状** |
| `degrade.noise` | `[~] 0.03` | |
| `degrade.oversharpen` | `[~] medium` | 边缘白边可见 |

### 关键观察（最重要的一类）

1. **中间的脸不动**：不是换脸，是五官移植。砂金的鼻、脸型、轮廓全保留。
2. **眼睛和嘴的形变方式完全不同**：眼是「横向拉 + 斜挑」，嘴是「双向放大」。**不能用一个统一变换。**
3. **色块边界靠"带皮圈"实现**：不是羽化，是故意多抠一圈皮肤。
4. **降质是核心手段**：downscale 0.60 + q35，靠糊掩盖接缝精度不足。

### 验收判据（量化）

> - **色差保留率 > 70%**（硬边，几乎不迁移色彩）
> - **边缘梯度**落在硬边带
> - 三档降质的**色差保留率差值 > 20pp**

## 四、A 类 · 精贴（REF-A）

**复刻目标**：写实中年脸塞进加拉赫的头，靠头发压住边缘。

### 结构拆解

| 元素 | 角色 | 观察 |
|---|---|---|
| 加拉赫 | 基底 | 暖色调、手持打火机 |
| 头发 | **前景遮挡层** | **压在写实脸的额头和两侧** |
| 写实中年脸 | 贴入内容 | 深肤色、胡茬、闭眼 |
| 打火机暖光 | 光照 | 下巴/脸颊有橙色光 |
| 钟表背景 | 背景 | 机械钟 |

### 参数表

| 参数 | 复刻值 | 备注 |
|---|---|---|
| `layers.foreground` | `[~]` 头发掩码 | **这一类的成败关键** |
| `layers.replace_zone` | `[~]` 脸部区域 | |
| `face_fit.center` | `[~] 0.5, 0.40` | |
| `face_fit.scale` | `[~] 1.0` | **不放大**（和 B 类相反） |
| `face_fit.edge` | `[~] none` | **不做边缘处理，全靠遮挡** |
| `face_fit.color_transfer` | `[~] 0.10~0.15` | 轻微，保留肤色差 |
| `face_fit.light_angle_deg` | `[~] -30°（左下暖光）` | 待校准 |
| `degrade.enabled` | `[~] false 或极轻` | **高频能量最高（0.0160）** |

### 关键观察（与技术路线最相关）

1. **遮挡 > 混合**：边缘之所以不露，不是因为羽化好，是因为**头发盖住了**。
2. **几乎不降质**：这是四张里最"清晰"的，实测高频能量 0.0160 最高。
3. **脸完全不放大**：和 B 类的「放大 5~8%」相反，A 类要比例正确。
4. **光照不完美对齐**：打火机暖光在人脸上略有偏差，而这个偏差**是加分项**（保留了一点违和）。

### 验收判据

> - 遮挡边界处**肉眼看不到接缝**
> - 人脸边界被前景层**覆盖 ≥ 30%**
> - 覆盖不足时**自动降级为 B 配方**

## 复刻操作步骤（每类通用）

1. 打开参考图，用 PS/GIMP 分层拆解——**每剥掉一层，截一次图**。
2. 量出每个元素的位置（用画布百分比，不要用像素）。
3. 记录所有"看不出来但确实存在"的处理（羽化几像素、锐化多少）。
4. 填进上面的参数表，`[~]` 改成具体数值。
5. 把 JSON 版本写进 `docs/baselines/<类>.json`。

**注意**：不要试图一次做到像素级一致。第一遍只要「结构对」，第二遍再调数值。
