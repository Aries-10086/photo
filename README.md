# 牢图棒

会记住你笑点的本地梗图工作台。两张素材进去，一张能发出去的牢图出来。

> **状态**：M0 完成（环境 + 数据模型 + 手工基线）
> **环境**：Windows 11 / R9 9955HX / RTX 5060 8G / 15.2 GB 内存
> **约束**：零 torch 依赖，进程内存 ≤ 1.5 GB，单图 ≤ 2048px

---

## 快速开始

```powershell
# 1. 激活环境（已建好 .venv）
.\.venv\Scripts\Activate.ps1

# 2. 跑验收测试
python tests\test_m0.py

# 3. 内存基线实测（M0 硬门）
python tools\mem_baseline.py

# 4. Schema 表达力评审
python tools\schema_review.py
```

三项都通过 = M0 完成。

## 三张表

| 表 | 文件 | 存储 | 一句话 |
|---|---|---|---|
| 素材卡 | `core/schema/asset.schema.json` | JSON | 一张素材能放哪、属于哪个语义域 |
| 配方 | `core/schema/recipe.schema.json` | JSON | 一次可复现的编辑计划 |
| 记忆 | `core/schema/memory.schema.json` | 单文件 YAML | 系统认为你喜欢什么 |

**三条铁律**：
1. 坐标一律归一化 0~1
2. 数值越界只 clamp 不报错
3. op 顺序由 `check_op_order` 校验，不靠 Schema

## 设计要点（踩过的坑）

| 要点 | 说明 |
|---|---|
| **不装 torch** | 省 3.9 GB 磁盘 + 1.5 GB 内存。所有 op 都是像素级几何运算 |
| **单模型驻留** | 任何时刻最多 1 个推理会话，用完即卸 |
| **降质是独立 op** | B 类靠糊取胜，A 类几乎不降质。不能全局默认开 |
| **前景遮挡 > 混合算法** | 头发压住人脸边缘，比任何羽化都有效且零成本 |
| **label 必须在 degrade 之后** | 先加字再降质会把字压糊，那是另一种风格 |
| **文字走真实字体** | 绝不用扩散模型画字 |

## 已知限制

| 限制 | 原因 | 缓解 |
|---|---|---|
| 无生成模型 | 8 GB 笔记本显存装不下 SDXL/FLUX | 素材不匹配时提示，不自动兜底 |
| A 类分层非全自动 | 单模型驻留约束 | 自动粗分 + 手动涂抹 |
| 单图 ≤ 2048px | 内存预算 | 超限自动等比缩小 |
| 无路径文字之外的排版能力 | v1 范围 | 用 `arc_deg` 覆盖常见需求 |
| 多基底拼图语义模糊 | base/asset 类型边界 | 记为已知弱项，v2 再拆 |
